# Δοκιμές αποδοχής

Μετά την εγκατάσταση, όλες οι παρακάτω αναζητήσεις πρέπει να επιστρέφουν πρώτο το αναμενόμενο σημείο.

| Ερώτημα | Αναμενόμενη χρονοετικέτα |
|---|---:|
| κινητική ενέργεια σε συνάρτηση με τον χρόνο | 00:06:00 |
| K=f(t) | 00:06:00 |
| σημεία τομής K και U | 00:12:10 |
| φάση σε συνάρτηση με τον χρόνο | 00:16:30 |
| κλίση της K=f(t) | 00:20:15 |
| ρυθμός μεταβολής κινητικής ενέργειας | 00:20:15 |
| πότε η κινητική ενέργεια μειώνεται | 00:20:30 |

## Έλεγχοι σε διαφορετικά μαθήματα

| Ερώτημα | Αναμενόμενο μάθημα |
|---|---:|
| έκρηξη με το πουλάκι | 043 |
| χωροεξάρτηση της δύναμης του ελατηρίου | 032 ή 037 |
| ενεργοποίηση ταλάντωσης μετά από κρούση | 037–042 |
| αρχική φάση | 020 ή 021 |
| πλάγια ελαστική κρούση με ακλόνητο τοίχο | 013 |

## Αρνητικοί έλεγχοι

- Χωρίς `X-API-Key`: HTTP 401.
- Με λάθος κλειδί: HTTP 401.
- Χωρίς παράμετρο `q`: HTTP 400.
- Με αίτημα για άλλο course: το API δεν δέχεται παράμετρο course και επιστρέφει μόνο `COURSES113`.
